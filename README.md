# Maintainer Skills Lab

Practical skills and focused agents for maintaining open-source repositories with Codex, Claude Code, Cursor, and Grok Bot.

The first implementation is being prepared in a pull request. It covers issue triage, bug reproduction, regression tests, fix verification, PR review, and release preparation, with shared source files and client-specific installation bundles.

## What we're building

- Six focused skills with concrete inputs, outputs, and examples.
- Three agent profiles, exported to each coding client's native format.
- Grok Bot setup recipes for issue summaries and release reports.
- A small installer, fixture-based checks, and an honest compatibility matrix.

See [ROADMAP.md](ROADMAP.md) for upcoming work. A format check is not a live-agent evaluation; we'll report those separately.
