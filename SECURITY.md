# Security Policy

## Reporting a Vulnerability
maintainer-skills-lab runs locally in your development environment and executes validation hooks on local codebases.

If you discover a security vulnerability (such as a command injection in git hook execution, SSRF vulnerability in watch fetching, or unauthorized file path traversal), please report it responsibly by opening a GitHub Security Advisory or contacting project maintainers directly.

## Supported Versions
Security updates are actively applied to the latest release on the `main` branch.
