# copilot

[All providers and source links](../README.md)

Install a compact `.github/copilot-instructions.md` compiled from core maintainer skills (PR review, regression tests, and maintainer replies). GitHub Copilot loads this file for Chat and PR review across VS Code, JetBrains, and GitHub.com.

For conflict detection, updates, and removal, use the installer from the source clone:

```sh
python3 tools/kit.py install --target copilot --project /existing/project
```

The installer writes one file and does not support `--skill` selection. Live-client discovery and task outcomes have not yet been evaluated.

Generated by `python3 tools/kit.py sync`. Edit the source, then regenerate.
