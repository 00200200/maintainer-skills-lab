# continue

[All providers and source links](../README.md)

Install Continue.dev prompt files into `.continue/prompts/` as invokable slash commands (type `/` in Chat, Plan, or Agent mode). Each skill becomes one `mkl-*.prompt` file with YAML frontmatter (`name`, `description`, `invokable: true`) and a `{{{ input }}}` placeholder for extra instructions. Continue has no separate agents directory here, so agent profiles are not exported.

For conflict detection, updates, and removal, use the installer from the source clone:

```sh
python3 tools/kit.py install --target continue --project /existing/project
```

The installer reads the canonical source and installs every skill prompt by default. Add `--skill mkl-humanize` to install or update only that prompt; repeat `--skill` to select more. Other prompts are preserved.

Skill prose is unchanged aside from frontmatter and the input placeholder. Live-client discovery and task outcomes have not yet been evaluated.

Generated by `python3 tools/kit.py sync`. Edit the source, then regenerate.
