These JSON files contain a `messages` array with one system prompt. Load one file, append your user message, and supply your chosen model to Groq's Chat Completions API. They contain no API key or model choice.

```python
import json
import os
from pathlib import Path

from groq import Groq

# Run from this Groq export directory.
prompt = json.loads(Path('skills/mkl-humanize.json').read_text())
response = Groq().chat.completions.create(
    model=os.environ['GROQ_MODEL'],
    messages=[*prompt['messages'], {
        'role': 'user',
        'content': 'Make this natural: We are thrilled to introduce preview mode.',
    }],
)
print(response.choices[0].message.content)
```

The application needs the `groq` Python package, `GROQ_API_KEY`, and a `GROQ_MODEL` available to your account. Running this example makes an API request; generation and validation of these files are offline. This example has not been tested against a live model.

These are instruction-only templates. Your application supplies task context, supporting resources, tool execution, and permissions. Loading a prompt does not give it access to your repository or implement an autonomous agent. Groq is separate from Grok Bot.
