# [Feature] Add Google Antigravity & Gemini CLI Exporter Target in `kit.py`

**Labels**: `enhancement`, `good first issue`

## Context & Motivation
Maintainer Skills Lab currently supports five AI client environments: Codex, Claude Code, Cursor, OpenCode, and Grok Bot.

Google has introduced **Antigravity (AGY)** and the **Gemini CLI** agentic ecosystem, featuring built-in skill discovery (`.gemini/antigravity/skills/` and workspace skills), specialized subagent orchestration, and native tool execution. Adding first-class support for Antigravity will allow maintainers using Google's agentic tools to install and run the 17 maintainer skills seamlessly.

## Prior Art & Industry Standards
- **Antigravity Skill Specification**: Skills are organized in `.gemini/antigravity/skills/<skill-name>/SKILL.md` with YAML frontmatter (`name`, `description`) and Markdown workflows.
- Existing provider generators in `tools/kit.py` (`TARGETS` dictionary for `claude`, `cursor`, `codex`, `opencode`).

## Proposed Solution
Add `antigravity` to `TARGETS` in `tools/kit.py`:
```python
TARGETS = {
    "codex": (".agents/skills", ".codex/agents", ".toml"),
    "claude": (".claude/skills", ".claude/agents", ".md"),
    "cursor": (".cursor/skills", ".cursor/agents", ".md"),
    "opencode": (".opencode/skills", ".opencode/agents", ".md"),
    "antigravity": (".gemini/antigravity/skills", ".gemini/antigravity/agents", ".md"),
}
```

### Specific Requirements
1. **Export Directory**: Export skills to `providers/antigravity/skills/` and agents to `providers/antigravity/agents/`.
2. **Manifest Generation**: Ensure Antigravity workspace layout is properly generated by `python3 tools/kit.py sync`.
3. **Installer Support**:
   - `python3 tools/kit.py install --target antigravity --project /path/to/repo`
   - Installs skills directly into `.gemini/antigravity/skills/`.
4. **Documentation**:
   - Add Antigravity setup instructions in `README.md` and `providers/README.md`.

## Implementation Tasks
- [ ] Add `antigravity` configuration to `TARGETS` in `tools/kit.py`.
- [ ] Update `providers/README.md` and `docs/install.md` with Antigravity quick-start instructions.
- [ ] Run `python3 tools/kit.py sync` to generate `providers/antigravity/` exports.

- [ ] Verify `python3 tools/kit.py check` and `python3 tools/kit.py build` succeed.

## Acceptance Criteria

- Running `python3 tools/kit.py install --target antigravity --project <dir>` copies skills to `.gemini/antigravity/skills/`.
- All tests pass in `tests/test_kit.py`.
